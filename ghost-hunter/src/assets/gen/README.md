# Generated art

Drop Higgsfield images and video here with these exact names. Each one is
optional: the game uses art drawn in code for anything missing. Rebuild
(`npm run build`) after adding files.

| File | Used for |
|---|---|
| `title.png` | title screen background |
| `ending.png` | win screen background |
| `intro.mp4` | intro cutscene (skippable) |
| `ending-video.mp4` | looping video behind the win screen |
| `face-queen.png` | Prom Queen jump scare |
| `face-janitor.png` | Janitor jump scare |
| `face-principal.png` | Principal Hale jump scare |
| `poster-missing.png` | corridor poster |
| `poster-prom.png` | corridor poster |
| `wall.png` | hallway wall colour map (should tile) |
| `floor.png` | hallway floor colour map (should tile) |

JPEG and WebP versions with the same base name also work.
